# 离线回归测试

在仓库根目录运行 `node --test tests/*.test.mjs`。测试使用 Node 内置测试框架和合成数据，不读取本地凭据，也不访问 kintone。

覆盖报告未知值、跨环境例外隔离、聚类稳定性、旧地图匹配和后台响应解析失败。脚本语法检查不能替代这些行为测试。

后台采集仅支持当前已审查的简体中文 CSV 列和页面数据结构；登录页、缺列或未知响应应显示为覆盖缺口。新语言和页面变体需要单独加入解析规则和 fixture。

`collection-reliability.test.mjs` 使用合成分页与故障响应验证目录中断后的重新发现、完整目录复用、来源状态隔离、429/503 退避、403 不重试和正文超时。所有故障注入均离线进行。
